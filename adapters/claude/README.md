# AI+ (Claude plugin)

AI+ keeps every Claude session efficient and accountable: the lead model plans and reviews, cheaper subagents execute, reads stay minimal, retries are capped, and each answer ends with a short evidence table. It works on claude.ai, Cowork, the desktop app and Claude Code.

## Use

Install it from the marketplace and it loads on its own at session start; you can also type `/aiplus`. The plugin is text only: no hooks, scripts or Python. The features that were hooks (agent notice, prompt nudge, evidence check, injection screen, plugin scan) are recipes Claude follows.

Rules are generated from `core/rules.md` in the repository root; see the root README for install, layout and what the recipes read.
